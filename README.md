## ⚡ Features
- 📱 **Installable PWA**: Runs natively on mobile and desktop with Web App Manifest and Service Worker caching.
- 🌐 **True Bilingual Flow**: Complete English and Persian (RTL) localization with automated font switching.
- 📝 **Markdown & Code Rendering**: Formatted responses with copyable syntax-highlighted code blocks.
